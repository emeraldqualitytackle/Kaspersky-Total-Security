## Usage

1. Download and extract the repository files.
2. Open the `/docs` folder and read the `GettingStarted.md` guide.
3. Choose your desired configuration:
   - **Presets:** Apply the security and privacy presets from `/presets` via Kaspersky's Settings menu.
   - **Scripts:** Run the automation scripts from `/scripts` for system optimization and custom rule deployment.
   - **Templates:** Import the parental control and firewall templates from `/templates`.
4. Launch Kaspersky Total Security and follow the documentation to apply your configurations.
